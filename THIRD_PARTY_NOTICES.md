# Dependencias y atribuciones

Los componentes de `frontend/src/components/ui/` adaptan los patrones y primitivas de shadcn/ui (MIT) y Radix UI (MIT) a los tokens de SOR Hosting. Iconos: Lucide (ISC). Consulte las licencias distribuidas por npm para React, Tailwind, Vite, TanStack Query y Recharts.

Las fuentes Fira Sans se distribuyen bajo SIL Open Font License 1.1. Se incluye la licencia junto a los archivos. Fira Code no estaba disponible offline y usa fallback monospace del sistema; puede añadirse como fuente local bajo su licencia OFL antes del ajuste visual final.
